# Synapse AI

A responsive SaaS landing page for an AI-powered design system platform. Built with React, Vite, Tailwind CSS, and Lucide React.

## Run locally

Requirements: Node.js 18+ and npm, pnpm, or yarn.

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open the local URL printed by Vite.

## Build for production

    npm run typecheck
    npm run build
    npm run preview

## Included interactions

- Responsive mobile navigation
- Live prompt demo state
- AI theme palette toggle
- Project-based design velocity calculator
- Monthly/yearly pricing switch
- Pricing CTA feedback states
- FAQ accordion
- Newsletter signup success state

The main page is in src/App.tsx, and the visual system is in src/index.css.
